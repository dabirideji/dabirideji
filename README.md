## About me

I'm a **Senior Backend Engineer** with **10+ years** in the .NET ecosystem, building enterprise-grade distributed systems.
I design and run scalable microservices, CI/CD pipelines and cloud-native infrastructure on **Azure** and **AWS**, and
I've led backend development for **fintech**, **healthcare SaaS** and **enterprise** platforms.

- **Architecture** - microservices, event-driven systems (Kafka, RabbitMQ), Domain-Driven Design, Clean Architecture
- **Delivery** - Docker, Kubernetes (AKS), Terraform and CI/CD pipelines, with DevOps practice built in from day one
- **Leadership** - project and team lead, solutions architect, and mentor to junior and intermediate developers
- **Fun fact** - I think differently.
